# TraumaTeam Webpage

A responsive, accessible site adhering to WCAG AAA standards, built with HTML5, CSS, and modern framework styling.

🔗 **Live Demo:** [https://allgoodusernamesaregone.github.io/traumateam-website/](https://allgoodusernamesaregone.github.io/traumateam-website/)

## Features
- Fully responsive design (Bootstrap / Flexbox)
- Accessibility & Ergonomics focused (WCAG AAA compliant contrast & semantic markup)
- Interactive elements (custom carousels / scripts)

## Technologies Used
- HTML5 (Semantic elements)
- CSS3 / Bootstrap
- JavaScript
